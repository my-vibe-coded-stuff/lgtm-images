# lgtm-images

Image pool for [lgtm-gacha](../lgtm-gacha). Drop images (png, jpg, jpeg, gif, webp) into the tier folders:

`one-star/` `two-star/` `three-star/` `nova/` `supernova/`

The filename (without extension) is shown as the "Pull" name in the PR comment. This repo must be public and pushed for the images to render.
